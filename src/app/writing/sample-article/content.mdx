## Start with a useful idea

Use this page as a starting point for an article, project note, or announcement.
Replace the title, description, date, and author in `page.tsx`.

### Add your content

Write in Markdown and use MDX components when you need richer content. You can
also add images beside this file and import them at the top of the page.

When you are ready, rename this folder to a URL-friendly slug. The article will
appear automatically on the homepage, writing page, sitemap, and RSS feed.
